Google Sheet Setup

Follow these steps to connect your Google Sheet as a CMS

Step-by-Step Guide
Follow these steps exactly. You only need to do this once.
1

Create Google Sheet & Open Apps Script

Go to sheets.new to create a new Google Sheet. Give it a name (e.g. "Khan Services"). In the top menu, click on Extensions > Apps Script.

2

Paste the Script Code

Open the file khan-services-sheet.gs from your website folder. Copy ALL the code inside it. Paste it in the Apps Script editor (replace existing code). Press Ctrl+S to save.

3

Create Template Sheet

In the Apps Script editor, select the function createTemplateSheet from the dropdown. Click the ▶ Run button. Allow permissions when asked. This creates your Google Sheet with all 25 services pre-filled!

4

Deploy as Web App

Click Deploy → New Deployment. Select type: Web App. Set "Execute as": Me. Set "Who has access": Anyone. Click Deploy and allow permissions.

5

Copy Your Web App URL

After deploying, you'll see a URL like https://script.google.com/macros/s/AKfycb.../exec. Copy that URL and paste it below!

Paste Your Web App URL
This URL connects your website to your Google Sheet.

✅ URL saved! The website will now load services from your Google Sheet.
